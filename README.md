# 过程数据系统 · 发布仓

本仓库存放 **过程数据系统（OilProcess）** 的安装包、完整更新包和 Velopack 更新元数据。

## 安装

下载最新 Release 中的 `OilProcess-win-Setup.exe`，双击安装。

## 自动更新

客户端默认更新源：

```
https://github.com/kaiz1995/Process-analysis-releases/releases/latest/download/
```

通道：`win`。更新包为 `OilProcess-<版本>-full.nupkg`，元数据为 `releases.win.json`。

## 源码

源码仓：https://github.com/kaiz1995/Process-analysis （私有）
